# ПрорабПро — иммерсивный сайт-портфолио

Сайт прораба в духе [atmos.leeroy.ca](https://atmos.leeroy.ca/): скролл листает
фоновое видео-пролёт по дому (кадры рисуются на канвас с кроссфейдом и инерцией —
движение плавное в обе стороны), поверх проявляются главы с этапами ремонта.
После «посадки» — обычные секции: статистика, портфолио, отзывы, контакты.

## Технологии

- Ванильные HTML/CSS/JS, сборка и внешние библиотеки не нужны
- Видео нарезано на 245 WebP-кадров (`img/bg/`), скраббинг по скроллу
- Фолбэк (reduced-motion или сбой загрузки): статичный кадр, главы обычными блоками

## Запуск

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Как заменить контент на свой

| Что | Где |
|---|---|
| Тексты глав полёта | `index.html`, блоки `.chapter` |
| Телефон, Telegram, WhatsApp | `index.html`, секция `#contact` |
| Тексты работ и отзывов | `index.html`, секции `#works` и `#reviews` |
| Цифры в статистике | `index.html`, атрибуты `data-count` |
| Фото работ | положите файлы в `img/` и в `css/style.css` замените фоны `.work__img--1…4` на `background-image: url("../img/work1.jpg")` |
| Фоновое видео | кадры в `img/bg/` (нарезка: `ffmpeg -i video.mp4 -vf "select='not(mod(n\,3))'" -vsync vfr -c:v libwebp img/bg/b_%03d.webp`), количество кадров — константа `FRAMES` в `js/journey.js` |
| Длина полёта | `css/style.css`, высота `.journey` (700vh) |

## Отправка формы

Сейчас форма показывает подтверждение без реальной отправки.
Чтобы получать заявки, подключите [Formspree](https://formspree.io) (бесплатно)
или Telegram-бота — место отмечено `TODO` в `js/main.js`.
