# ПрорабПро — иммерсивный сайт-портфолио

Сайт прораба в духе [atmos.leeroy.ca](https://atmos.leeroy.ca/) (Awwwards Site of the Day):
скролл управляет 3D-полётом бумажного самолётика сквозь облака, небо меняет цвет
от рассвета до сумерек, а главы рассказывают этапы ремонта. После «посадки» —
обычные секции: статистика, портфолио, отзывы, контакты.

## Технологии

- Three.js (с CDN, через importmap) — небо с шейдерным градиентом, процедурные
  облака, маршрут по сплайну Catmull-Rom (генерируется заново при каждой загрузке)
- Ванильные HTML/CSS/JS, сборка не нужна
- Фолбэк без WebGL: главы показываются обычными блоками

## Запуск

Нужен локальный сервер (ES-модули не работают с file://):

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Как заменить контент на свой

| Что | Где |
|---|---|
| Тексты глав полёта | `index.html`, блоки `.chapter` |
| Телефон, Telegram, WhatsApp | `index.html`, секция `#contact` |
| Тексты работ и отзывов | `index.html`, секции `#works` и `#reviews` |
| Цифры в статистике | `index.html`, атрибуты `data-count` |
| Фото работ | положите файлы в `img/` и в `css/style.css` замените фоны `.work__img--1…4` на `background-image: url("../img/work1.jpg")` |
| Скролл-видео «Пролёт по объекту» | кадры лежат в `img/fly/` (нарезаны из видео: `ffmpeg -i video.mp4 -vf "select='not(mod(n\,7))',scale=540:960" -vsync vfr -c:v libwebp img/fly/f_%03d.webp`), количество кадров — константа `FRAMES` в `js/main.js`, длина секции — высота `.flythrough` в CSS |
| Цвета неба по этапам | `js/experience.js`, массив `palettes` |
| Длина полёта | `css/style.css`, высота `.journey` (700vh) |
