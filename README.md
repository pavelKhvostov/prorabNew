# ПрорабПро — сайт-портфолио

Одностраничный сайт прораба: услуги, портфолио работ, отзывы клиентов и форма заявки.
Дизайн в стиле glassmorphism (полупрозрачное «стекло», как у Apple) с динамичными анимациями.

## Запуск

Сборка не нужна — это статичный сайт. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Как заменить контент на свой

| Что | Где |
|---|---|
| Телефон, Telegram, WhatsApp | `index.html`, секция `#contact` |
| Тексты работ и отзывов | `index.html`, секции `#works` и `#reviews` |
| Цифры в статистике | `index.html`, атрибуты `data-count` в `.hero__stats` |
| Фото работ | положите файлы в папку `img/` и в `css/style.css` замените фоны `.work__img--1…4` на `background-image: url("../img/work1.jpg")` |

## Отправка формы

Сейчас форма показывает подтверждение без реальной отправки.
Чтобы получать заявки, подключите [Formspree](https://formspree.io) (бесплатно) или Telegram-бота — место для кода отмечено `TODO` в `js/main.js`.

## Публикация

Самый простой способ — GitHub Pages: Settings → Pages → Deploy from branch → выберите ветку и корень репозитория.
